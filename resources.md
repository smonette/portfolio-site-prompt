I collected a few resources that might be helpful as you embark on this project:

## Generally helpful sites:
- [CSS Tricks](https://css-tricks.com/) is amazing. They have great demos, and inspirational work, as well as just good info about key concepts.

## HTML:
- [HTML cheatsheet](https://web.stanford.edu/group/csp/cs21/htmlcheatsheet.pdf)
- [Basic HTML course](https://www.codecademy.com/learn/learn-html)

## CSS concepts:
- [The box model](https://css-tricks.com/the-css-box-model/)
- [Display](https://css-tricks.com/almanac/properties/d/display/)
- [A really good demo of Display](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/display)
- [What is a CSS reset?](https://cssdeck.com/blog/what-is-a-css-reset/)
